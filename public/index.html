치지직을 연결해 볼까요?

서버에 치지직 앱 설정이 아직 없어요. 앱 설정 후 서버를 다시 시작하면 연결할 수 있어요.

  1. 치지직 개발자 센터에서 앱을 등록해 주세요.
  2. 유저 정보 조회와 채팅 메시지 조회 권한을 설정해 주세요.
  3. 로그인 리디렉션 URL을 아래 주소로 등록해 주세요.http://localhost:3000/auth/chzzk/callback
  4. 서버의 .env에 Client ID와 Client Secret을 입력해 주세요. 비밀 키는 브라우저에 입력하지 않아요.

방송 시작 전, 딱 세 가지만

  1. 채널 연결

    치지직 연결 버튼으로 스트리머 계정에 로그인해요. 모집을 켜면 시청자가 채팅 한 번을 입력하는 즉시 참가해요.

  2. 목소리 확인

    진행자 브라우저에서 TTS를 켜고 음성 테스트를 눌러 주세요. 당첨자의 일반 채팅은 최대 150자씩 차례대로 읽어요.

  3. OBS 소리 확인

    이 브라우저의 소리를 OBS에서 캡처하도록 설정한 뒤, 오디오 미터와 짧은 녹화로 확인해 주세요. 소리는 진행자 브라우저에서만 켜 두세요.

발언권은 당첨 즉시 45초. 시간 종료·발언권 종료·연결 끊김 시 음성과 대기열을 함께 멈춰요. 숫자 투표와 확률 룰렛은 위 탭에서 사용할 수 있어요.
